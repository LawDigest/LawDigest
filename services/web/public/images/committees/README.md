# 국회 위원회 로고

국회 위원회 공식 사이트의 헤더 로고 자산을 저장한 디렉터리입니다.

- 출처 CSS: `https://committee.na.go.kr/static/cmmit/css/style.css?ver=2411113`
- 수집 스크립트: `services/web/scripts/fetch-committee-logos.mjs`
- 원본 경로 형식: `https://committee.na.go.kr/commitee/{committee}/img/m_logo_{committee}.jpg`

위원장안 발의자 카드에서 위원회 로고를 표시하기 위해 사용합니다.
